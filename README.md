# Study Tracker Dashboard 📊

A Flask-based web application designed to help students track and analyze daily study sessions.

## Features
- Subject-wise study tracking
- Date-based study history
- Weekly progress visualization using Chart.js
- Most studied subject analytics
- JSON-based persistent storage
- Responsive dashboard UI

## Tech Stack
- Python
- Flask
- HTML
- CSS
- JavaScript
- Chart.js
- JSON
